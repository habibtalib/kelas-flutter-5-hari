## Nota Penyelarasan Modul

Bahan kursus dalam repositori ini **mengikut aturcara rasmi di atas**. Perhatikan:

- **`setState()` ialah state management rasmi kursus** (SESI 5). Pakej `provider` & `shared_preferences` **di luar** aturcara — dikekalkan sebagai **nota bonus/lanjutan** sahaja.
- **Tiada sesi deployment / `flutter build apk`** dalam aturcara. Hari 5 ialah **projek mini + clean code + refactoring + demo**. Nota deployment dikekalkan sebagai **bonus**.
- **🤖 Slot AI** ialah item aturcara rasmi pada SESI 2, 5, 7 dan teras SESI 8–9 — bukan sekadar modul bonus.
