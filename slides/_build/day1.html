💬 Terjumpa operator yang tak biasa (cth. ~/ atau ??=) dalam kod orang lain nanti? Tanya sahaja AI — "Apa beza / dengan ~/ dalam Dart, bagi contoh guna kuota program" — lebih pantas daripada scroll dokumentasi setiap kali.
Jangan hafal — tunjuk yang setiap kategori sudah muncul dalam contoh tadi. Sebut sekali lalu: soalan sintaks kecil macam ni memang sesuai ditanya terus pada AI dalam kerja harian. Rujukan rasmi: dart.dev/language/operators.

Control Flow — if / else


const String keperluanProgram = 'stam'; // ETT-002: Syariah

if (keperluanProgram == 'both') {

Control Flow — switch


String countryLabelForUniversity(String universityName) {
  switch (universityName) {
    case 'Universiti Al-Azhar':
    case 'Universiti Alexandria':
    case 'Universiti Ain Shams':
    case 'Universiti Tanta':
      // empat case "jatuh melalui" (fall-through) ke return sama
      return 'Mesir';
    case 'Universite Al Quaraouiyine':
    case 'Universiti Mohammed V':
      return 'Maghribi';
    default:
      return 'Negara tidak diketahui';
  }
}
💡 switch lebih kemas daripada rantaian if/else if panjang bila membandingkan satu nilai dengan banyak kemungkinan tetap.
Domain sebenar: memetakan universiti eTT ke label negara BM. Tunjuk fall-through — empat universiti Mesir berkongsi satu return. Cuba 'Universiti Kaherah' untuk lihat default.

Looping (for) & Function


// Function — jumlahkan quotaSeats semua program dalam senarai.
int jumlahkanKuota(List<Map<String, Object>> data) {
  int jumlah = 0;
  for (final programme in data) {   // for (... in ...)
    jumlah += programme['quotaSeats'] as int;
  }
  return jumlah;
}

void main() {
  final jumlah = jumlahkanKuota(sampleProgrammes);
  print('Jumlah kuota keseluruhan (8 program): $jumlah tempat'); // 340
}
💬 Nak lebih latihan sebelum move on? Minta AI: "Beri saya 3 latihan Dart pendek pakai for untuk kira purata quotaSeats daripada senarai program, tahap pemula" — cuma taip & jalankan sendiri jawapannya, jangan sekadar baca.
Function ada nama, parameter bertaip dan nilai pulangan. Loop for-in melelar setiap program tanpa urus indeks. Jumlah 340 tempat — angka latihan yang boleh peserta sahkan sendiri di DartPad. AI bagus untuk jana soalan latihan tambahan ikut tahap masing-masing.

Looping — while


const senaraiBidangPopular = [
  'Perubatan (Medicine)',
  'Farmasi (Pharmacy)',
  'Pergigian (Dentistry)',
];

int i = 0;
while (i < senaraiBidangPopular.length) {
  print('Bidang popular #${i + 1}: ${senaraiBidangPopular[i]}');
  i++; // PENTING: jangan lupa naikkan i
}
⚠️ Kesilapan biasa pemula: lupa i++ → syarat kekal true selamanya → infinite loop, program "tersangkut". Pastikan syarat berhenti pasti tercapai.
Guna while bila bilangan lelaran tidak diketahui awal. Demokan infinite loop dalam DartPad sekali — pengalaman "tersangkut" lebih diingati daripada amaran lisan.

enum + switch Expression


enum EntryCategory {
  spm,
  stam,
  both;

  String get label => switch (this) {
        EntryCategory.spm => 'SPM',
        EntryCategory.stam => 'STAM',
        EntryCategory.both => 'SPM atau STAM',
      };

  bool accepts(EntryCategory applicant) =>
      this == EntryCategory.both || this == applicant;
}

Corak sebenar daripada models/programme.dart projek kursus — Dart 3 switch expression (=>) memulangkan satu nilai terus. Model juga ada enum StudyLevel (Asasi/Diploma/Ijazah Sarjana Muda).

Ini pratonton model sebenar yang kita guna penuh Hari 2. Bandingkan: switch statement untuk logik bercabang berbilang baris, switch expression untuk pulangkan satu nilai. Method accepts() menjawab: adakah sijil pemohon layak untuk program ini?

Function — Format Kos Anggaran ke RM


/// Format kos tahunan (RM), cth. 23000.0 -> "RM23,000".
/// Kos adalah anggaran latihan, bukan sebut harga rasmi.
String formatCostMyr(double amount) {
  final wholeNumber = amount.toStringAsFixed(0);
  final buffer = StringBuffer();
  for (var i = 0; i < wholeNumber.length; i++) {
    final posFromRight = wholeNumber.length - i;
    buffer.write(wholeNumber[i]);
    if (posFromRight > 1 && posFromRight % 3 == 1) {
      buffer.write(',');
    }
  }
  return 'RM${buffer.toString()}';
}
💡 Gabungan semua topik pagi: function + loop + operator (%, >, &&). Hari 2 kita guna pakej intl (NumberFormat.currency) untuk kerja sama secara automatik.
Latihan penutup pagi: format 23000.0 jadi RM23,000. Snippet penuh boleh dijalankan: hari-1/snippets/dart_asas.dart. Kos diselaras kasar dengan jadual USD rasmi 2021/22 — anggaran latihan.

Padding vs Margin

PaddingMargin
MaksudJarak DALAM — sempadan widget ↔ kandungannyaJarak LUAR — sempadan widget ↔ sekelilingnya
AnalogiRuang dalam bingkai gambar, sekitar gambarRuang di luar bingkai, sebelum dinding
Dalam Containerpadding: EdgeInsets.all(16)margin: EdgeInsets.all(16)
Widget berasingan?Ya — Padding(padding: ..., child: ...)Tiada widget Margin — parameter sahaja
💡 EdgeInsets.all(16) · EdgeInsets.symmetric(horizontal: 12, vertical: 8) · EdgeInsets.only(top: 8, left: 16)

StatelessWidget vs StatefulWidget

StatelessWidgetStatefulWidget
Bila gunaUI tidak berubah selepas dibinaUI perlu berubah — interaksi pengguna / data dalaman
Contoh projekProgrammeCard (papar sahaja — Hari 2)Kaunter, borang permohonan (Hari 3)

💡 Analogi: StatelessWidget = gambar bercetak (tak berubah). StatefulWidget = papan tanda LED (boleh dikemas kini bila-bila masa).
Beza paling asas dalam Flutter — peserta akan tulis kedua-duanya setiap hari sepanjang kursus. Analogi gambar bercetak vs papan LED biasanya melekat.

Teaser: setState() — Kaunter "Simpan Program"


class _SavedProgrammeCounterState
    extends State<SavedProgrammeCounter> {
  int _savedCount = 0; // data yang boleh BERUBAH

  void _addProgramme() {
    setState(() {
      _savedCount++; // "data berubah, lukis semula build()"
    });
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        Text('Program disimpan: $_savedCount'),
        const SizedBox(height: 8),
        ElevatedButton(
          onPressed: _addProgramme,
          child: const Text('+ Simpan Program'),
        ),
      ],
    );
  }
}
🔭 Pratonton sahaja — kitaran hayat penuh StatefulWidget (initState(), dispose(), dsb.) dibedah di SESI 5 (Hari 3).
Tekan butang berulang kali — angka naik tanpa run semula. Tegaskan: tanpa setState(), nilai berubah di belakang tabir tetapi UI TIDAK dikemas kini.
