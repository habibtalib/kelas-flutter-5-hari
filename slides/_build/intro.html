Kenapa Flutter?

  • Hot Reload — lihat perubahan < 1 saat
  • Widget kaya (Material 3) terbina dalam
  • Prestasi hampir native (compile ke ARM)
  • Komuniti & ekosistem pakej besar (pub.dev)

  • Google (Google Pay, Classroom)

  • eBay Motors, Alibaba (Xianyu)

Asas Dart (1) — Pembolehubah & Null Safety


var universityName = 'Universiti Al-Azhar'; // jenis diinfer: String
final int quotaSeats = 40;      // sekali set, tak boleh tukar
const String country = 'Egypt'; // pemalar masa kompil

String? note;                 // '?' = boleh null (null safety)
print(note ?? 'Tiada nota');  // '??' = nilai lalai jika null
  • var infer jenis · final tetap selepas set · const pemalar kompil
  • String? boleh null; String dijamin tidak — Dart tangkap ralat null sebelum run
Null safety ialah ciri paling penting Dart moden — jenis tanpa tanda soal dijamin tidak null oleh compiler. Peserta akan jumpa corak ?? dan ? sepanjang kursus, contohnya submittedAt yang boleh null dalam model Application.

Asas Dart (2) — Function


// Function biasa: parameter bertaip + jenis pulangan
int jumlahkanKuota(List<int> kuota) {
  int jumlah = 0;
  for (final k in kuota) {
    jumlah += k;
  }
  return jumlah;
}

// Arrow function — badan satu ungkapan
double convertUsdToMyrEstimate(double usd) => usd * 4.6;

Bentuk => (arrow) sesuai untuk function satu baris — banyak dalam kod Flutter. Kadar 4.6 = anggaran latihan sahaja, bukan kadar rasmi.

Function Dart sentiasa nyatakan jenis parameter dan pulangan. Esok kita guna function seperti ini untuk jumlahkan kuota 8 program eTT.

Asas Dart (3) — Class & fromJson


class Programme {
  final String id;
  final String universityName;
  final double estimatedAnnualCostMyr; // anggaran latihan

  const Programme({
    required this.id,
    required this.universityName,
    required this.estimatedAnnualCostMyr,
  });

  factory Programme.fromJson(Map<String, dynamic> json) => Programme(
        id: json['id'] as String,
        universityName: json['universityName'] as String,
        estimatedAnnualCostMyr:
            (json['estimatedAnnualCostMyr'] as num).toDouble(),
      );
}
Ini versi ringkas model sebenar projek (lib/models/programme.dart). Factory fromJson ialah jambatan JSON API → objek Dart — kemahiran teras Hari 4 (SESI 7).

Asas Dart (4) — Asynchronous: Future, async, await


Future<List<Programme>> fetchProgrammes() async {
  final response = await http.get(Uri.parse(apiUrl));
  final List data = jsonDecode(response.body) as List;
  return data
      .map((j) => Programme.fromJson(j as Map<String, dynamic>))
      .toList();
}
  • Future = "nilai yang akan tiba nanti" (cth. balasan API)
  • await tunggu tanpa membekukan UI

Diterangkan penuh pada Hari 4 (SESI 6) — hari ini cukup kenal bentuknya.

Jangan mendalam di sini — sekadar pendedahan bentuk sintaks supaya tidak asing bila tiba Hari 4. Analogi: pesan makanan, dapat nombor giliran (Future), sambung buat kerja lain sehingga makanan sampai (await).
